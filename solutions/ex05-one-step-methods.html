Problem 1: Logistic growth (5 points)

A population \(u(t)\) grows with the rate \(r > 0\) as long as it is small, and its growth stops at the carrying capacity \(K > 0\):

\[ \frac{\mathrm{d}u}{\mathrm{d}t} = r \, u \left( 1 - \frac{u}{K} \right), \qquad u(0) = u_0 , \qquad 0 < u_0 < K . \]

  1. Solve the equation by separation of variables. Use the partial fraction decomposition \(\dfrac{1}{u (1 - u/K)} = \dfrac{1}{u} + \dfrac{1}{K - u}\) (check it first). Show that \[ u(t) = \frac{K}{1 + \left( K / u_0 - 1 \right) e^{-r t}} . \]

  2. Take \(r = 1\), \(K = 10\), \(u_0 = 1\), and integrate to \(t = 5\) with the forward and the backward Euler method for the time steps \(\Delta t = 0.5, 0.25, 0.125, 0.0625, 0.03125\). For backward Euler, write down the equation \(G(U) = 0\) for \(U = u_{n+1}\) and its derivative \(G'(U)\), and solve it with Newton’s method. Compute the signed errors \(u_n - u(5)\) at \(t = 5\) and the observed orders \(p = \log_2 \big( |E(\Delta t)| / |E(\Delta t / 2)| \big)\). Do the orders agree with the theory? Compare the signs of the errors of the two methods and explain them with the local truncation errors of section 5.4.

Solution

a) Partial fractions. Bringing the right hand side to a common denominator, \(\frac{1}{u} + \frac{1}{K - u} = \frac{K - u + u}{u (K - u)} = \frac{K}{u (K - u)} = \frac{1}{u (1 - u/K)}\), as claimed.

Separation. Since \(0 < u_0 < K\), and the constant solutions \(u = 0\) and \(u = K\) cannot be crossed (two solutions through one point would contradict uniqueness), \(0 < u(t) < K\) for all \(t\). We may therefore divide by \(u (1 - u/K) > 0\) and integrate over time from 0 to \(t\), substituting \(u\) as the integration variable on the left:

\[ \int_{u_0}^{u(t)} \left( \frac{1}{u} + \frac{1}{K - u} \right) \mathrm{d}u = \int_0^t r \, \mathrm{d}t \quad \Longrightarrow \quad \Big[ \ln u - \ln (K - u) \Big]_{u_0}^{u(t)} = r t . \]

Both logarithms are defined, because \(u > 0\) and \(K - u > 0\). Hence

\[ \ln \frac{u(t)}{K - u(t)} - \ln \frac{u_0}{K - u_0} = r t \quad \Longrightarrow \quad \frac{u}{K - u} = \frac{u_0}{K - u_0} \, e^{r t} . \]

Solving for \(u\): \(u = (K - u) \, q\) with \(q = \frac{u_0}{K - u_0} e^{rt}\) gives \(u (1 + q) = K q\) and \(u = \frac{K q}{1 + q} = \frac{K}{1 + 1/q} = \frac{K}{1 + \left( \frac{K}{u_0} - 1 \right) e^{-rt}}\), since \(\frac{1}{q} = \frac{K - u_0}{u_0} e^{-rt}\). This is the claimed solution.

For \(t \to \infty\), \(u \to K\): the population approaches the carrying capacity. With \(r = 1\), \(K = 10\), \(u_0 = 1\): \(u(5) = 10 / (1 + 9 e^{-5}) = 9.42826\).

b) Newton’s method for backward Euler. With the logistic tendency, the backward Euler step \(u_{n+1} = u_n + \Delta t \, f(u_{n+1})\) is the root of

\[ G(U) = U - u_n - \Delta t \, r \, U \left( 1 - \frac{U}{K} \right) , \qquad G'(U) = 1 - \Delta t \, r \left( 1 - \frac{2 U}{K} \right) . \]

For \(0 < U < K\) the bracket \(1 - 2U/K\) lies between \(-1\) and \(1\), so \(G'(U) > 1 - r \Delta t \ge 0.5\) for all time steps used here (\(r \Delta t \le 0.5\)): Newton’s method never divides by zero. Starting value \(U^{(0)} = u_n\), as in the script.

import numpy as np

r, K, u0, t_end = 1.0, 10.0, 1.0, 5.0      # growth rate, capacity, start value, end time

def f_logistic(t, u):
    # tendency of the logistic equation; t is not used but kept for the form f(t, u)
    return r * u * (1 - u / K)

def dfdu_logistic(t, u):
    # derivative of the tendency with respect to u, needed by Newton's method
    return r * (1 - 2 * u / K)

def u_exact(t):
    # exact solution from a)
    return K / (1 + (K / u0 - 1) * np.exp(-r * t))

def euler_forward(f, u0, t_end, dt):
    # forward Euler from t = 0 to t_end; returns the state at t_end
    u = u0
    for n in range(round(t_end / dt)):
        u = u + dt * f(n * dt, u)            # u_{n+1} = u_n + dt f(t_n, u_n)
    return u

def euler_backward(f, dfdu, u0, t_end, dt, tol=1e-12, max_iterations=20):
    # backward Euler from t = 0 to t_end, Newton's method in each step;
    # returns the state at t_end
    u = u0
    for n in range(round(t_end / dt)):
        t_new = (n + 1) * dt
        U = u                                # starting value U^(0) = u_n
        for m in range(max_iterations):
            G = U - u - dt * f(t_new, U)     # G(U), zero at the new state
            if abs(G) < tol:
                break
            U = U - G / (1 - dt * dfdu(t_new, U))   # Newton update U - G/G'
        u = U                                # the new state u_{n+1}
    return u

dt_list = [0.5, 0.25, 0.125, 0.0625, 0.03125]
for name, method in [("forward", lambda dt: euler_forward(f_logistic, u0, t_end, dt)),
                     ("backward", lambda dt: euler_backward(f_logistic, dfdu_logistic, u0, t_end, dt))]:
    errors = [method(dt) - u_exact(t_end) for dt in dt_list]          # signed errors u_n - u(5)
    orders = [np.log2(abs(errors[i - 1]) / abs(errors[i])) for i in range(1, len(errors))]
    print(f"{name:8s}: errors " + " ".join(f"{e:+.2e}" for e in errors))
    print(f"          orders  " + " ".join(f"{p:.2f}" for p in orders))
forward : errors +8.41e-02 +3.77e-02 +1.80e-02 +8.81e-03 +4.36e-03
          orders  1.16 1.07 1.03 1.01
backward: errors -6.15e-02 -3.23e-02 -1.66e-02 -8.47e-03 -4.28e-03
          orders  0.93 0.95 0.97 0.99

Orders. Both observed orders approach 1, as derived in section 5.4: halving \(\Delta t\) halves the error. For the larger time steps they deviate slightly, because the error behaves like \(C \Delta t\) only for small \(\Delta t\).

Signs. Forward Euler ends above the exact solution, backward Euler below it, with errors of about the same size. Section 5.4.2 explains why: in each step the local truncation errors are \(\tau_n = +\frac{\Delta t^2}{2} u''(\xi_n)\) for forward Euler and \(\tau_n = -\frac{\Delta t^2}{2} u''(\eta_n)\) for backward Euler, with \(\xi_n\), \(\eta_n\) in the same interval. They have the same size to leading order and opposite signs, step by step, and so do the global errors that they add up to. For the logistic curve \(u''\) changes its sign at the inflection point \(u = K/2\), so the local errors of each method change sign during the run; they stay opposite to each other throughout.

Points: a) 2, b) 3.

Problem 2: Cooling with a daily cycle (4 points)

A body with temperature \(T(t)\) (in °C, time \(t\) in hours) exchanges heat with its surroundings, whose temperature \(T_a(t)\) follows a daily cycle:

\[ \frac{\mathrm{d}T}{\mathrm{d}t} = -k \, \big( T - T_a(t) \big), \qquad T_a(t) = 15 + 5 \sin \frac{2 \pi t}{24} , \qquad T(0) = 25 , \]

with the exchange coefficient \(k = 0.2 \ \mathrm{h}^{-1}\). Unlike the equations in the script, the tendency depends on \(t\).

  1. Write down one step of the backward Euler method for this equation and solve it for \(T_{n+1}\). Why is no Newton iteration needed here?

  2. Integrate for three days, \(0 \le t \le 72\) h, with forward and backward Euler, for \(\Delta t = 1\) h and \(\Delta t = 12\) h. As a reference, use forward Euler with \(\Delta t = 0.001\) h; since the method is of first order, its error is about 1000 times smaller than with \(\Delta t = 1\) h. Plot the results and explain what each method does at \(\Delta t = 12\) h. Hint: print the ambient temperature \(T_a(t_n)\) at the times \(t_n\) that the methods use.

Solution

a) The backward Euler method evaluates the tendency at the new time \(t_{n+1}\) and the new state \(T_{n+1}\):

\[ T_{n+1} = T_n - k \, \Delta t \, \big( T_{n+1} - T_a(t_{n+1}) \big) . \]

The unknown \(T_{n+1}\) appears only linearly, so we collect it on the left, \(T_{n+1} (1 + k \Delta t) = T_n + k \Delta t \, T_a(t_{n+1})\), and divide:

\[ T_{n+1} = \frac{T_n + k \, \Delta t \, T_a(t_{n+1})}{1 + k \, \Delta t} . \]

No Newton iteration is needed because the tendency is linear in \(T\); the implicit equation is solved exactly by this division. \(T_a(t_{n+1})\) is a known number, since the time \(t_{n+1}\) is known.

b)

import matplotlib.pyplot as plt

k = 0.2                                      # exchange coefficient in 1/h
T_start, t_stop = 25.0, 72.0                 # initial temperature in degC, end time in h
# (new names, so that u0 and t_end of Problem 1 stay unchanged)

def T_air(t):
    return 15 + 5 * np.sin(2 * np.pi * t / 24)   # ambient temperature, period 24 h

def f_cooling(t, T):
    return -k * (T - T_air(t))               # tendency; depends on t through T_air

def forward_euler(dt):
    t = dt * np.arange(round(t_stop / dt) + 1)    # times t_n = n dt
    T = np.empty(t.size)
    T[0] = T_start
    for n in range(t.size - 1):
        T[n + 1] = T[n] + dt * f_cooling(t[n], T[n])
    return t, T

def backward_euler(dt):
    t = dt * np.arange(round(t_stop / dt) + 1)
    T = np.empty(t.size)
    T[0] = T_start
    for n in range(t.size - 1):              # the formula from a)
        T[n + 1] = (T[n] + k * dt * T_air(t[n + 1])) / (1 + k * dt)
    return t, T

# reference: forward Euler with a small time step; first order, so its error is
# about 1000 times smaller than with dt = 1 h
dt_ref = 0.001
t_ref = dt_ref * np.arange(round(t_stop / dt_ref) + 1)
T_ref = np.empty(t_ref.size)
T_ref[0] = T_start
for n in range(t_ref.size - 1):
    T_ref[n + 1] = T_ref[n] + dt_ref * f_cooling(t_ref[n], T_ref[n])

fig, axes = plt.subplots(1, 2, figsize=(10, 3.4), sharex=True)
for ax, dt in zip(axes, [1.0, 12.0]):
    t_fe, T_fe = forward_euler(dt)
    t_be, T_be = backward_euler(dt)
    ax.plot(t_ref, T_ref, "k", lw=1, label="reference (forward Euler, dt = 0.001 h)")
    ax.plot(t_ref, T_air(t_ref), color="0.7", lw=1, label="ambient $T_a$")
    ax.plot(t_fe, T_fe, "o-", ms=3, label="forward Euler")
    ax.plot(t_be, T_be, "s-", ms=3, label="backward Euler")
    ax.set_title(rf"$\Delta t$ = {dt:g} h, $k \Delta t$ = {k * dt:g}", fontsize=10)
    ax.set_xlabel("$t$ in h")
    print(f"dt = {dt:4.1f} h: T(72) forward {T_fe[-1]:8.3f}, backward {T_be[-1]:8.3f},"
          f" reference {T_ref[-1]:.3f}")
axes[0].set_ylabel("$T$ in °C")
axes[1].set_ylim(-60, 100)
axes[0].legend(fontsize=8)
plt.tight_layout()
plt.show()

With \(\Delta t = 1\) h (\(k \Delta t = 0.2\)) both methods follow the reference closely: after 72 h they are about 0.3 °C off, with opposite signs, as expected from local errors of equal size and opposite sign.

With \(\Delta t = 12\) h (\(k \Delta t = 2.4\)) both fail, in different ways:

  • Forward Euler is unstable. Without the forcing, one step multiplies the distance from the ambient temperature by \(1 - k \Delta t = -1.4\). Its magnitude exceeds 1, so the deviation changes sign and grows by 40 % in every step. After 72 h the “temperature” is about 90 °C, which is physically impossible: the body can never be warmer than the warmest surroundings (20 °C) or its initial 25 °C. This is the instability of the decay equation for \(k \Delta t > 2\) from the script.
  • Backward Euler is stable but blind to the daily cycle. The factor \(1/(1 + k\Delta t) = 0.29\) damps every deviation, and the solution settles at 15 °C. But the ambient temperature is evaluated only at \(t = 12, 24, 36, \dots\) h, where \(\sin(2\pi t/24) = \sin(\pi n) = 0\): the method sees a constant \(T_a = 15\) °C. Two samples per period of a sine fall exactly on its zeros, the invisible shortest wave of unit 4, here in time. The daily cycle is lost completely.

Stability is necessary, but it does not make a result accurate: the time step must also resolve the time scales of the forcing, here the 24 h cycle.

Points: a) 2, b) 2.
